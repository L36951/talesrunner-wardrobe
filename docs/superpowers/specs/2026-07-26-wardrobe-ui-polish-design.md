# 衣櫃 UI 執整：對齊遊戲版面

2026-07-26

把配裝分享器嘅版面改到貼近《跑Online》原本嘅道具視窗。範圍限於版面同視覺，
唔郁資料層（`data/items.json`）同配裝／能力值計算邏輯。

參考：遊戲道具視窗截圖，同用家提供嘅兩個裝備欄 SVG。

## 範圍

四項改動，全部喺 `index.html`：

1. 分頁由右上角搬去格仔下面、置中，改用數字頁碼
2. 子 tab 右對齊、緊貼分類 tab 下面
3. 裝備欄改用 SVG 面板
4. Avatar mode 開關改成「邊粒掣著燈」，移除整條欄去色

明確唔做：卡片耐久條同 `修理` 掣（呢個網冇耐久概念）、底部三個篩選下拉、
補三個空 tab。呢啲留返之後再傾。

## 1. 分頁

**而家**：`#gridPager` 喺 `.wardrobe-links` 右邊，得 `« ‹ 1/98 › »` 加件數。

**改成**：搬去 `.wardrobe-grid` 下面、置中，顯示數字頁碼。

上衣有 98 頁，全部列出會爆行，所以用**視窗式頁碼**：

```
« ‹  1 … 6 7 [8] 9 10 … 98  › »
```

- 永遠顯示第一頁同最後一頁
- 顯示當前頁 ±2
- 中間斷開嘅位置用 `…`（唔可以撳）
- 只有一頁嘅時候淨係顯示件數，唔顯示頁碼

件數（`共 2,374 件`）繼續顯示，擺喺頁碼右邊。

`.wardrobe-body` 而家係 `inset:42px 0 40px`，`.wardrobe-grid` 高 464px。
分頁佔一行之後，格仔高度要相應收窄，維持 4×4 唔變。

## 2. 子 tab

`.wardrobe-links` 由「子 tab 左 ＋ 分頁右」變成單純子 tab。

**左邊對齊當前大 tab 嘅左邊，向右伸展；唔夠位先向左推到啱啱貼右邊。**

```
left = clamp(當前 tab 嘅左邊, 容器左邊界, 容器右邊界 - 子tab 總寬)
```

量度時要留意 `.game` 有 `transform:scale()` —— `getBoundingClientRect()` 係縮放後嘅值，
但 `marginLeft` 要用佈局像素，所以要除返個 scale。基準用「margin 0 時嘅位置」，
咁就自動包咗容器嘅 `padding-left:3px`。

`fit()`（視窗 resize）之後要重新定位。

橫向捲動（`overflow-x:auto`）保留 —— 飾品有 10 個子 tab，窄視窗仍然需要。

## 3. 裝備欄 SVG 面板

兩個檔案放入 `assets/ui/`，改名去掉誤導：

| 來源 | repo 檔名 | 用途 |
|---|---|---|
| `slotpanel_active.svg` | `slot-panel-avatar.svg` | Avatar 裝備欄（藍） |
| `slotpanel_inactive.svg` | `slot-panel-role.svg` | 角色裝備欄（灰） |

> ⚠️ 原檔名嘅 active／inactive **唔係狀態**，係兩條唔同嘅欄。改名就係為咗
> 唔好再誤導 —— 兩條欄各自永遠用自己嗰個檔，唔會因為選中而換圖。

### 幾何

SVG viewBox `728 × 3096`，格位規律：

```
x    = 64（左欄）/ 384（右欄）
y    = 304 + 312 × row      row = 0..7
size = 280
```

換成百分比（畀 CSS 絕對定位用）：

```
left   = 64/728  = 8.791%      384/728 = 52.747%
top    = (304 + 312×row) / 3096
width  = 280/728 = 38.462%
height = 280/3096 = 9.044%
```

SVG 做 `background-image`，`background-size:100% 100%`。

### 格位對應

2 欄 × 8 行 = 16 格，現有 15 個部位剛好排得晒，最後一格留空（同 SVG 一樣）。
次序同現有 `slotDefs` 完全吻合，唔使改：

| 行 | 左 | 右 |
|---|---|---|
| 0 | 頭部 | 髮型 |
| 1 | 臉部 | 上衣 |
| 2 | 頸部 | 褲/裙 |
| 3 | 手部 | 鞋子 |
| 4 | 手環 | 寵物 |
| 5 | 背部 | 特殊 |
| 6 | 助推器 | 珠寶 |
| 7 | 尾 | （空） |

### 空格

SVG 本身已經畫咗每格嘅部位圖示，所以**空格唔使 render 任何嘢** ——
移除現有嘅 unicode 符號（`♙〽◉♜⌁»◆≈`）同 `.rail-slot` 背景。

著咗嘅裝備 icon 疊喺格上面。已著（金邊）同被佔用（紅底 ×）嘅高亮照舊。

## 4. Avatar mode 開關

遊戲入面係一個 toggle，用兩粒掣表達，邊粒著燈就係邊個 mode：

- `Avatar` 掣著燈 ＝ Avatar mode **ON**
- `角色` 掣著燈 ＝ Avatar mode **OFF**

**改動**：移除 `.rail:not(.active-target)` 嘅 `filter:saturate(.55) brightness(.9)`
同 `opacity:.76` —— 兩條欄永遠保持自己顏色。改為淨係喺著燈嗰粒掣上面做
發光／實色處理。

`activeLoadout` 呢個 state 同佢對能力值計算嘅影響**完全唔變**，只改視覺表達。

## 驗證

改完要確認：

- 分頁：揀上衣（98 頁）睇省略號正唔正常；跳去最後一頁、第一頁；只有一頁嘅分類（例如搜尋窄結果）唔應該出頁碼
- 子 tab：飾品 10 個子 tab 喺窄視窗仲捲動得到
- 裝備欄：16 格對位準唔準（著幾件唔同部位嘅裝備，睇 icon 有冇偏）；空格顯示 SVG 圖示
- Avatar mode：撳兩粒掣，能力值跟住變（Avatar 欄計 Avatar+角色、角色欄只計角色），兩條欄顏色都唔應該變

## 風險

**格位對位**係主要風險。SVG 係固定比例，但 `.rail` 喺 `.room` 入面用緊 px 定位
（`width:72px`）。如果 SVG 嘅長寬比同 `.rail` 唔一致，格位就會偏。
實作時要按 SVG 比例（728:3096 ≈ 1:4.25）重設 `.rail` 尺寸，唔可以夾硬塞。
